# MagicalMod

Мод на Fabric для Minecraft **1.21.11**: магия через жесты (последовательности действий, как в Hogwarts Legacy) и групповые ритуалы, где участники отдают всю ману лидеру и его заклинание становится намного сильнее и выглядит иначе.

## Возможности

- **Мана** — 100 единиц, медленно восстанавливается (1/сек), сохраняется в файле игрока.
- **Жесты** — набор.actions, которые нужно выполнить подряд:
  - 🔥 Огненный шар: **присесть → прыжок → вправо → влево**
  - ❄️ Ледяной удар: **прыжок → влево → вправо → присесть**
  - 💚 Исцеление: **присесть → присесть → прыжок**
  - ⚡ Молния: **вправо → вправо → влево → прыжок**
  - Поворот считается при резком движении мыши (не при обычном осмотре).
- **Групповая магия** — лидер создаёт круг, игроки рядом отдают всю ману в общий резервуар. Следующее заклинание лидера:
  - тратит резервуар и усиливается (×1.0 ... ×6.0);
  - бьёт по области вокруг цели;
  - имеет другой визуал: цветная сфера, душа-огонь, END-лучи, свечение и взрыв;
  - объявляется всем игрокам сервера.
- **Команды** — `/magic mana`, `/magic gestures`, `/magic circle start|join|leave|status|stop`.

## Как играть

1. Установите [Fabric Loader 0.20.1](https://fabricmc.net/use/) для Minecraft 1.21.11.
2. Положите `fabric-api-0.141.6+1.21.11.jar` и собранный jar мода в `mods`.
3. Введите `/magic gestures` — список жестов.
4. Выполните жест и посмотрите на игровой оверлей: он показывает распознанные действия.
5. Для групповой магии:
   - лидер: `/magic circle start`
   - участники в радиусе 16 блоков: `/magic circle join`
   - лидер выполняет жест → усиленное заклинание
   - `/magic circle stop` — отмена с возвратом маны участникам

## Сборка

Для сборки нужна **Java 25+** (таково требование Loom 1.19.x); для запуска мода в игре достаточно Java 21 (Minecraft 1.21.11).

```bash
./gradlew build
```

Готовый файл: `build/libs/magicalmod-1.0.0.jar`.

Для IDEA/Eclipse: `./gradlew genIdeaRuns` / `./gradlew genEclipseRuns`.

## Структура

```
src/main/java/com/magicalmod/       общая и серверная логика
  MagicalMod.java                   точка входа
  magic/                            мана, заклинания, ритуалы, каст
  command/                          команды /magic
  net/                              сетевой пакет жеста
  mixin/                            сохранение маны в ServerPlayer
src/client/java/com/magicalmod/client/  клиентская часть (распознавание жестов)
src/main/resources/                 fabric.mod.json и конфиг миксинов
```
