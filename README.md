# MagicalMod

Мод на Fabric для Minecraft **1.21.11**: магия через жесты (как в Hogwarts Legacy) и групповые ритуалы через меню. Участники отдают ману лидеру — его заклинание становится сильнее и выглядит иначе.

## Управление

- **G** — меню круга магии.
- **]** (правая квадратная скобка, настраивается в «Управление») — каст по введённому жесту. Клавиша выбрана специально, чтобы не конфликтовать со стандартными биндами.
- **/magic gestures** — список жестов, **/magic mana** — текущая мана.

Жест вводится молча (без спама в чат/оверлей). После нажатия **]** мод проверяет последовательность и кастует заклинание; если жест не распознан — показывает одно сообщение и очищает ввод.

## Жесты

- 🔥 Огненный шар: **присесть → прыжок → вправо → влево**
- ❄️ Ледяной удар: **прыжок → влево → вправо → присесть**
- 💚 Исцеление: **присесть → присесть → прыжок**
- ⚡ Молния: **вправо → вправо → влево → прыжок**

Поворот считается только при резком движении мыши (не при обычном осмотре).

## Групповая магия

Меню по **G** с кнопками «Создать круг», «Вступить», «Выйти», «Обновить», «Расформировать». В окне видны лидер, запас маны и число участников. Участники в радиусе 16 блоков отдают всю ману; следующее заклинание лидера тратит резервуар, усиливается (×1.0 … ×6.0), бьёт по области и получает особый визуал.

## Мана и HUD

- Мана: 100 единиц, +1/сек, сохраняется в данных игрока.
- **Полоса маны рисуется над шкалой голода** через Fabric HUD API с регистрацией высоты, поэтому не перекрывает другие полосы.

## Анимации

При касте игрок размахивает рукой; вокруг точки заклинания крутится цветное кольцо. У усиленного заклинания кольцо больше, с END-лучами, душа-огнём и вертикальным лучом. Количество одновременных эффектов ограничено, частицы создаются один раз на эффект.

## Сборка

Для сборки нужна **Java 25+** (Loom 1.19.x), для запуска — Java 21.

```bash
./gradlew build
```

Готовый jar: `builds/MagicalMod-1.0.0.jar` (также `build/libs/`).
