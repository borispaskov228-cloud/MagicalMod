# MagicalMod

Мод на Fabric для Minecraft **1.21.11**: магия через жесты (последовательности действий, как в Hogwarts Legacy) и групповые ритуалы через специальное меню. Участники отдают всю ману лидеру — его заклинание становится намного сильнее и выглядит иначе.

## Возможности

- **Мана** — 100 единиц, восстанавливается 1/сек, сохраняется в данных игрока.
- **Жесты** — действия выполняются подряд (поворот считается только при резком движении мыши):
  - 🔥 Огненный шар: **присесть → прыжок → вправо → влево**
  - ❄️ Ледяной удар: **прыжок → влево → вправо → присесть**
  - 💚 Исцеление: **присесть → присесть → прыжок**
  - ⚡ Молния: **вправо → вправо → влево → прыжок**
- **Меню круга (клавиша G)** — групповое управление без команд:
  - «Создать круг», «Вступить в круг», «Выйти», «Обновить», «Расформировать»;
  - в меню отображаются лидер, запас маны и число участников;
  - участники в радиусе 16 блоков отдают всю ману в общий резервуар;
  - следующее заклинание лидера тратит резервуар, усиливается (×1.0 … ×6.0), бьёт по области, имеет другой визуал и объявляется всем игрокам.
- **Анимации** — при касте игрок размахивает рукой, а вокруг точки заклинания крутится цветное кольце; у усиленного заклинания кольцо больше, с END-лучами, душа-огнём и вертикальным лучом.
- **Справочные команды** — `/magic mana`, `/magic gestures` (управление кругом только через меню).

## Как играть

1. Fabric Loader **0.20.1** + Fabric API **0.141.6+1.21.11**.
2. Положите jar мода из папки `builds/` (или собранный `build/libs/`) в `mods`.
3. `/magic gestures` — список жестов; выполняйте их подряд.
4. Нажмите **G** — откроется меню круга. Создайте круг; участники рядом нажимают «Вступить в круг».
5. Лидер выполняет жест → групповое заклинание.
6. «Расформировать» возвращает ману участникам.

## Сборка

Для сборки нужна **Java 25+** (требование Loom 1.19.x); для запуска мода — Java 21.

```bash
./gradlew build
```

Готовый файл: `build/libs/MagicalMod-1.0.0.jar`. Готовый jar также лежит в репозитории: `builds/MagicalMod-1.0.0.jar`.

## Структура

```
src/main/java/com/magicalmod/          общая и серверная логика
  magic/                               мана, жесты, заклинания, круг, FX
  command/                             справочные команды
  net/                                 сетевые пакеты
  mixin/                               сохранение маны
src/client/java/com/magicalmod/client/ жесты, меню, анимации
src/client/resources/assets/.../lang   локализация
src/main/resources/                    fabric.mod.json и миксины
builds/                                готовый jar
```
