# MagicalMod

Мод на Fabric для Minecraft **1.21.11**: магия через жесты, прокачка маны и групповые ритуалы в кастомном меню.

## Управление

- **G** — кастомное меню круга магии.
- **]** — каст по введённому жесту.
- **`,` / `.`** — шаги жеста «влево/вправо» (свободные клавиши, не конфликтуют с WASD и мышью).
- `/magic gestures`, `/magic mana`, `/magic book`.

Все клавиши переназначаются: Управление → категория **MagicalMod**.

## Жесты и эффекты

Ввод жеста живёт **12 секунд** — успеть легко. Сообщений при вводе нет; результат появляется только после нажатия **]**.

| Заклинание | Жест | Эффект |
|---|---|---|
| 🔥 Огненный шар | присесть → прыжок → `.` → `,` | Урон + поджог (5 сек / 10 в группе), восходящая спираль пламени и дым |
| ❄️ Ледяной удар | прыжок → `,` → `.` → присесть | Урон, замедление, заморозка; расширяющийся ледяной круг и снег |
| 💚 Исцеление | присесть → присесть → прыжок | Лечит кастера всегда; столбики сердечек и зелёное свечение |
| ⚡ Молния | `.` → `.` → `,` → прыжок | Урон; зигзагообразная молния, искры и END-лучи |

У каждого заклинания свой рисунок частиц, а не только свой цвет. Групповой вариант добавляет цветную сферу, душа-огонь, взрыв и особые звуки.

## Прокачка маны

- За каждый каст даётся опыт (2 очка, 4 за групповой).
- 10 очков = новый уровень: **+20 к максимуму маны**, всего до 10 уровня.
- Уровень и опыт сохраняются в данных игрока и переносятся при респавне.
- Полоса над голодом показывает текущую ману, максимум, уровень и узкую полоску опыта.

## Книга-инструкция

Выдаётся при первом входе прямо в 9-й слот хотбара. Есть кликабельное оглавление (переход по страницам). Потерянную вернёт `/magic book`.

## Групповая магия

Кастомное меню с анимированной рамкой, руной и стилизованными кнопками: «Создать круг», «Вступить», «Выйти», «Обновить», «Расформировать». Круг привязан к измерению; участники в радиусе 16 блоков отдают ману лидеру. Оповещения идут только nearby игрокам.

## Сборка

Для сборки **Java 25+** (Loom 1.19.x), для запуска Java 21.

```bash
./gradlew build
```

Готовый jar: `builds/MagicalMod-1.0.0.jar`.
