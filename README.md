# MagicalMod

Мод на Fabric для Minecraft **1.21.11**: магия через жесты и групповые ритуалы.

## Управление

- **G** — меню круга магии.
- **]** — каст по введённому жесту (настраивается в «Управление»).
- **/magic gestures** — жесты, **/magic mana** — мана, **/magic book** — выдать книгу-инструкцию.

Жест вводится **только свободными клавишами**: приседание, прыжок, **`,` (влево)** и **`.` (вправо)**. Мышь и WASD не участвуют — прицел и ходьба не сбиваются. Все клавиши переназначаются в «Управление» → категория MagicalMod. Лишних сообщений при вводе нет — результат появляется только после нажатия **]**.

## Жесты и эффекты

- 🔥 Огненный шар: **присесть → прыжок → `.` → `,`**. Урон + поджог на 5 сек (10 сек в группе).
- ❄️ Ледяной удар: **прыжок → `,` → `.` → присесть**. Урон, сильное замедление и полная заморозка врага.
- 💚 Исцеление: **присесть → присесть → прыжок**. Всегда лечит кастера, даже если вокруг нет целей.
- ⚡ Молния: **`.` → `.` → `,` → прыжок**.

Если прицел не попал, заклинание всё равно ищет ближайшего врага в радиусе 8 блоков.

## Групповая магия

Меню по **G**: «Создать круг», «Вступить», «Выйти», «Обновить», «Расформировать». Участники в радиусе 16 блоков отдают ману; следующее заклинание лидера усиливается и получает особый визуал.

## Книга-инструкция

При первом входе игрок получает написанную книгу «MagicalMod — инструкция» с жестами, эффектами и управлением. Если книга потеряна — `/magic book`.

## Мана и HUD

Мана: 100 единиц, +1/сек, сохраняется в данных игрока. Полоса маны рисуется над шкалой голода через Fabric HUD API и не перекрывает ванильные шкалы.

## Сборка

Для сборки нужна **Java 25+** (Loom 1.19.x), для запуска — Java 21.

```bash
./gradlew build
```

Готовый jar: `builds/MagicalMod-1.0.0.jar`.
