# MagicalMod

Мод на Fabric для Minecraft **1.21.11**: магия через жесты, прокачка маны и групповые ритуалы в кастомном меню.

## Управление

- **\\** (обратная косая) — кастомное меню круга магии; `G` в 1.21.11 занят ванильным Quick Actions.
- **]** — **рисование магии**: удерживайте клавишу и ведите мышью, отпустите — каст.
- `/magic mana` — мана и уровень; `/magic gestures` — список форм.
- `/magic book` — книга; `/magic guide` — красивый GUI-гид (открывается и правым кликом по книге).
- `/magic refill` — полное восстановление маны.
- `/magic level <0-10>` — задать уровень маны.
- `/magic potions` — 3 зелья маны (+30 / +60 / +100); `/magic herb` — 8 травы маны.
- `/magic staffs` — 3 посоха; `/magic boss` — призыватель Архимага Пустоты.

Все клавиши переназначаются: Управление → категория **MagicalMod**.

## Рисование магии

Вместо последовательностей клавиш теперь нужно **нарисовать форму мышью**. Удерживайте `]`, ведите мышь (на экране рисуется светящийся след), отпустите — мод распознаёт форму и кастует заклинание.

| Заклинание | Форма |
|---|---|
| 🔥 Огненный шар | Круг по часовой стрелке |
| ❄️ Ледяной удар | Треугольник |
| 💚 Исцеление | V |
| ⚡ Молния | Зигзаг (Z) |
| ☠️ Яд | Спираль |
| 🌊 Водный поток | Волна |
| 🌪️ Ветровой порыв | Горизонтальная линия |
| 🛡️ Магический щит | Квадрат |
| ☄️ Метеорит | Вертикальная линия вниз |
| 🌀 Притяжение | Стягивающаяся спираль |

Заклинания **летят зарядом** от игрока к цели — эффект срабатывает при попадании, а не появляется из ниоткуда. У заряда есть цветной шлейф; при попадании — вспышка.

У каждого заклинания свой рисунок частиц, а не только свой цвет. Групповой вариант добавляет цветную сферу, душа-огонь, взрыв и особые звуки.

**Дальность:** полёт заряда — 12 блоков (18 в группе), 6 для исцеления/щита; радиус урона по области — 3 (6).

## Прокачка маны

- За каждый каст даётся опыт (2 очка, 4 за групповой).
- 10 очков = новый уровень: **+20 к максимуму маны**, всего до 10 уровня.
- Уровень и опыт сохраняются в данных игрока и переносятся при респавне.
- Полоса над голодом показывает текущую ману, максимум, уровень и узкую полоску опыта.

## Книга-инструкция

Выдаётся при первом входе прямо в 9-й слот хотбара. Есть кликабельное оглавление (переход по страницам). Потерянную вернёт `/magic book`.

## Групповая магия

Кастомное меню с анимированной рамкой, руной и стилизованными кнопками: «Создать круг», «Вступить», «Выйти», «Обновить», «Расформировать». Круг привязан к измерению; участники в радиусе 16 блоков отдают ману лидеру. Оповещения идут только nearby игрокам.

## Трава и зелья маны

`magicalmod:mana_herb` — светящееся растение (ставится как блок, ломается мгновенно, даёт траву). Из неё крафтятся три зелья маны:
- малое: 1 трава + стеклянная бутылка;
- среднее: 2 травы + бутылка;
- большое: 3 травы + аметистовый осколок + бутылка.

Зелья восстанавливают 30 / 60 / 100 маны и имеют собственные текстуры.

## Посохи

Три посоха усиливают урон заклинаний, если держать их в основной или дополнительной руке:
- Посох новичка — ×1.25
- Посох адепта — ×1.6
- Посох архимага — ×2.2

Берётся максимальный множитель из двух рук (не суммируется). Крафт из ванильных материалов; текстуры и модели свои.

## Босс: Архимаг Пустоты

`/magic boss` даёт призыватель. У босса три фазы:

1. **>70% HP** — стихийные снаряды, барьеры и зоны телепортации.
2. **30–70%** — призывает 3–4 Vex, которые дают ему щит, пока живы.
3. **<30%** — быстрые касты, притяжение игрока, порталы и взрывные руны.

Магический урон наносит ×1.75 и сбивает щит (убивая приспешников). За победу — «Ядро Архимага», аметист, эндер-жемчуг и незеритовый лом. Босс имеет собственную модель и босс-бар.

## Гид

Вместо тесной ванильной книги — кастомный интерфейс в стиле FTB Quests: вкладки «Начало», «Формы магии», «Заклинания», **«Крафты»** (со всеми рецептами посохов и зелий и иконками предметов), «Круг и мана», «Босс». Текст разбит на страницы с переносами, есть стрелки и прокрутка. Открывается командой `/magic guide` или правым кликом по книге.

## Сборка

Для сборки **Java 25+** (требование Loom 1.19.x); код и запуск мода рассчитаны на Java 21 (`--release 21`).

```bash
./gradlew build
```

Готовый jar: `builds/MagicalMod-1.0.0.jar`.
